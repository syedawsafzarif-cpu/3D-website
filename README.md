# 🚀 Syed Awsaf Zarif Portfolio V2.0


## 🌌 About

A futuristic personal portfolio website built from scratch using pure HTML, CSS, and JavaScript.

Designed with inspiration from:

- Apple
- Framer
- Vercel
- Nothing
- ROG


The goal is to create a smooth, premium, interactive experience that feels like a professional developer portfolio.
